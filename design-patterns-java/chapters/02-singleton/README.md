# 第 02 章：单例模式 Singleton

## 场景与选择

进程内配置中心必须唯一。示例使用 Java 枚举单例：类加载线程安全、天然抵抗常规反射构造与序列化破坏，代码也最短。单例只保证**当前 ClassLoader 内唯一**，不代表跨 JVM 或分布式唯一。

## 验证

程序启动 32 个并发任务获取 `Configuration.INSTANCE`，用对象身份集合验证只有一个实例；同时验证不同调用点共享同一配置状态。

```powershell
.\scripts\run.ps1 02
```

练习：将实现替换为静态内部类，再运行同样的并发验收。业务代码中若需要隔离测试或多份配置，优先通过依赖注入管理生命周期，不要滥用全局状态。
