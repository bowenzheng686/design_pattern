# 第 18 章：设计模式实战速查

## 可执行速查工具

资料强调“从问题出发，而不是为用模式而用模式”。本章把高频需求映射为模式建议，同时返回替代方案和引入条件；默认演示 5 个问题，也可传关键词查询。

```powershell
.\scripts\run.ps1 18
.\scripts\run.ps1 18 undo
.\scripts\run.ps1 18 incompatible
```

关键词包括 `unique`、`complex-create`、`incompatible`、`dynamic-feature`、`algorithm`、`undo`、`notify`、`simplify`、`pipeline`、`internal-state`。查询结果只用于缩小候选集：引入前仍需确认变化点已真实出现，并比较简单实现的成本。
